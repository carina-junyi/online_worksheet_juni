📘 一元一次方程式的解法與應用

A-7-3 互動式學習講義

🎯 學習目標

  • 理解「等量公理」：等式左右兩邊同時進行加、減、乘、除（除數不為 0）運算，等式依然成立。
  • 明白「移項法則」是由等量公理簡化而來（左邊 +2 移到右邊變 -2；乘 3 移到右邊變除以 3）。
  • 掌握解題黃金步驟：先將所有含未知數的項集中在一側、常數項集中在另一側，最後再求出解。
  • 學會含有分數方程式的「去分母」技巧，並養成將解代回原始情境「驗算」的好習慣。

1️⃣ 等量公理天秤律

若已知 a = b，則：
• 加減： a + c = b + c ｜ a - c = b - c
• 乘除： a × c = b × c ｜ a ÷ c = b ÷ c (c ≠ 0)。

天秤兩邊動作必須完全一樣才平衡！

2️⃣ 移項法則口訣

跨越等號 = 就像過海關，必須變換運算符號：
• + 變 - ｜ - 變 +
• × 變 ÷ ｜ ÷ 變 ×。

例：x + 2 = 3 ➔ x = 3 - 2 = 1

3️⃣ 最佳解題黃金步驟

1. 有分母先去分母（每一項都要乘）
2. 有括號先拆括號（分配律）
3. 移項整理成 Ax = B 形態
4. 兩邊同除以 A 求出 x。

先移加減，最後再處理乘除！

解題示範：移項法則步驟與口香糖應用題

1 純代數移項：解 -x + 8 = 3x + 4

步驟 1 (未知數集中)：左右同加 x ➔ 8 = 3x + 4 + x ➔ 8 = 4x + 4

步驟 2 (常數項集中)：左右同減 4 ➔ 8 - 4 = 4x ➔ 4 = 4x

步驟 3 (習慣寫法)：將未知數寫在左邊 ➔ 4x = 4

步驟 4 (求出解答)：左右同除以 4 ➔ x = 1！

2 口香糖應用題與驗算

情境：老師帶 2 盒口香糖，每人發 2 條給 26 個學生後剩 8 條，原一盒有幾條？

依題意列式：設一盒有 x 條 ➔ 2x - 52 = 8

移項求解：2x = 8 + 52 ➔ 2x = 60 ➔ x = 30

代回驗算：一盒 30 條，2 盒共 60 條。發給 26 人共發 52 條，60 - 52 = 8 條，驗算完全正確！

⚠️ 解方程式的三大常見迷思

  • ❌ 去分母漏乘常數項？ 錯！解 x/2 + x/3 = 1 兩邊同乘 6 時，右邊的 1 也必須乘以 6 變 6（不可寫成 3x + 2x = 1）！
  • ❌ 未移項即提前除法？ 錯！解 3x - 6 = 9 時，應先將 -6 移項變 +6 得 3x = 15，最後才除以 3（不可直接除以 3 得 x - 6 = 3）！
  • ❌ 同除以負數忘記變號？ 錯！解 -4x = 20 兩邊同除以 -4 時，右邊正負號改變為 -5！

💡 生活中的等量邏輯

移項法則就像生活中的「收支平衡」！
1. 購物退貨： 買衣服 3x + 200 = 800 元，辦理 200 元退貨相當於把 +200 移到右邊變成 800 - 200 = 600 元！
2. 平分帳單： 3x = 600 元，平分到 3 個人身上就是 600 ÷ 3 = 200 元。
3. 代回驗算習慣： 算完結果代回生活情境驗算，確保零錢與數量完全精準！
