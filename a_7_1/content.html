📘 代數符號

A-7-1 互動式學習講義

🎯 學習目標

  • 理解用英文字母（如 x, y, a, b）代表未知數及省略乘號簡寫的約定。
  • 能辨識一次式中的「同類項」，並進行加減合併與化簡。
  • 透過板塊與動態展開體驗，熟練掌握交換律、結合律與分配律的代數表徵。
  • 能用代數式記錄生活情境（如商品總額、年齡差距、長方形面積）。

1️⃣ 符號簡寫與約定

數字與字母相乘可省略乘號：2 × a = 2a；1 × a = a；(-1) × a = -a；(4/7)x = 4x/7。

2a 代表「2 個 a」或「a 的 2 倍」！

2️⃣ 同類項加減合併

含有相同未知數或純數字的項叫同類項。例如：x 與 -2x、3y 與 y、1 與 3 均可合併！

x + 1 + 3y - 2x + y + 3 = -x + 4y + 4

3️⃣ 三大運算律密碼

交換律：a + b = b + a
結合律：(a + b) + c = a + (b + c)
分配律：a(b + c) = ab + ac。

分配律展開時，括號內每一項都要乘！

解題示範：園遊會收款與代數式化簡

情境：班上有 1000 元鈔票 x 張、500 元鈔票 y 張。請列出總金額，並計算當 x = 3、y = 1 時的金額。另外化簡式子：3(x + 1) - 2x + 1。

1

記錄生活情境：總金額表示為 1000x + 500y 元。代入 x = 3、y = 1 得 1000(3) + 500(1) = 3500 元。

2

分配律拆括號：3(x + 1) 要把 3 乘進去！得 3 × x + 3 × 1 = 3x + 3。原式變為：3x + 3 - 2x + 1。

3

同類項合併：將 3x 與 -2x 合併得 x；數字 3 與 1 合併得 4。化簡結果為 x + 4！

🔍 觀念引導：破解代數式化簡的兩大陷阱

挑戰：化簡算式「3(x + 1) - 2x + 1」，小明寫出 3x + 1 - 2x + 1 = x + 2，請問他哪裡算錯了？

1️⃣ 檢查第一步【分配律】：3 乘進去括號 3(x + 1) 時，數字 3 有沒有乘給常數項 1？

2️⃣ 賓果！正確展開為 3x + 3 - 2x + 1 後，將同類項合併，最終化簡結果是多少？

🧩 練習 1：步驟引導！用代數式記錄生活情境

題目情境：長方形的長為 5 公分、寬為 x 公分。請列出長方形的周長與面積代數式。

步驟 1️⃣：長方形【面積】等於「長 × 寬」，省略乘號後如何表示？

步驟 2️⃣：長方形【周長】等於 2 × (長 + 寬) = 2(5 + x)，利用分配律展開化簡後是多少？

完全正確！成功學會代數列式！

• 面積 = 5 × x = 5x 平方公分。
• 周長 = 2(5 + x) = 2 × 5 + 2 × x = 10 + 2x 公分！

⚠️ 代數式化簡三大迷思

  • ❌ 拆括號漏乘常數項？ 錯！3(x + 1) = 3x + 3，數字 3 必須同時乘給 x 與 1！
  • ❌ 同類項正負號算錯？ 錯！3 - 2x + 7x 化簡時，-2x + 7x = +5x，故結果為 3 + 5x（不可寫成 3 - 9x）！
  • ❌ 分式約分只約一邊？ 錯！(9x - 3) / 3 化簡時，分子兩項都要除以 3，結果為 3x - 1（不可寫成 3x - 3）！
