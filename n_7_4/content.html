1️⃣ 交換律

$a + b = b + a$ $a \times b = b \times a$

2️⃣ 結合律

$(a + b) + c = a + (b + c)$ $(a \times b) \times c = a \times (b \times c)$

3️⃣ 分配律

$a(b + c) = ab + ac$

4️⃣ 去括號陷阱

💡 訣竅：負號進入括號，內部「每一項」都要變號。

$-(a + b) = -a - b$
$-(a - b) = -a + b$

常見迷思

  • ❌
    減法交換律

    $3 - 5$ 不等於 $5 - 3$，順序不可隨便換。

  • ❌
    漏掉分配律的後項

    $2 \times (3 + 5)$ 必須兩項都乘到，不能只乘 $3$。

  • ❌
    $-(8 - 3) = -8 - 3$？

    錯！負號要讓括號內每一項都變號，應該是 $-8 + 3$。
